Account Settings demo
=====================

Files:
- index.html: page structure
- style.css: responsive styling
- script.js: demo interactions

How to run:
1. Keep all files in the same folder.
2. Open index.html in a browser.
3. Internet is needed for Google Fonts, Font Awesome icons, and the sample profile image.

Important:
This is a front-end demonstration. Password changes, account updates, real 2FA, session revocation,
and account deletion require a secure backend. No real account changes are performed by this demo.
